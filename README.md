# Проверка карточки

Бесплатный открытый виджет TehProf для amoCRM: подсказки о пробелах,
невидимых символах, подозрительном формате и повторах телефонов/email
внутри открытой карточки контакта или компании.

**Статус:** подготовка к живой установке и модерации. В amoMarket ещё не опубликован.
Скриншоты тура показывают демонстрационный стенд с вымышленными данными.

## Использование

После установки сохраните контакт или компанию, откройте виджет справа
и нажмите «Проверить». По нажатию выполняется один GET сохранённой карточки
через API этого же аккаунта. Исправления делаются вручную в обычных полях.

Виджет не обходит базу, не ищет дубли между карточками и не подтверждает
существование телефона, почтового ящика или доставку сообщения.
Международные и специальные форматы могут требовать ручной проверки.

Данные обрабатываются в браузере, не отправляются разработчику, не сохраняются
виджетом. Нет внешнего сервера, аналитики и автоматических изменений.

## Локальная проверка

Нужны Node.js с `node:test` и Python 3. Сторонние пакеты не нужны.

```sh
node --test tests/*.test.cjs
python3 tools/package.py
python3 -m http.server 8791 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8791/demo/>. Стенд исполняет настоящие
`widget/script.js` и `widget/lib/checks.js`, заменяя SDK и ответы API
локальными сценариями. Он не подключается к amoCRM и не заменяет проверку
установленного виджета в контакте и компании.

При установленном `agent-browser` и запущенном локальном сервере можно
выполнить `python3 tools/browser_qa.py`: 14 сценариев интерфейса, включая
ошибки доступа, HTML в значениях, стоимость запросов и пересоздание виджета.

Сборщик проверяет manifest, переводы, размеры изображений и формирует
`dist/widget.zip` и его SHA-256 в `dist/manifest.json`.
В архив входят только файлы из `widget/`; демонстрация и тесты не включаются.
