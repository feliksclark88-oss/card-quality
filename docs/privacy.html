Данные и конфиденциальность

Дата документа: 26 сентября 2026 года. Приложение «Проверка карточки», разработчик TehProf. Контакт по всем вопросам обработки данных: support@tehprof.kz.

Какие данные нужны виджету

По вашему нажатию кнопки виджет запрашивает сохранённую карточку текущего контакта или компании через API вашего аккаунта amoCRM. Для проверки используются значения стандартных полей телефона и email. Ответ API может включать другие атрибуты карточки; они не используются для анализа и не сохраняются виджетом.

Где происходит обработка

Проверка выполняется в браузере пользователя. Виджет не передаёт карточки, телефоны и email разработчику или внешним сервисам, не устанавливает собственные cookie, не использует localStorage и не отправляет аналитику. Он не запрашивает пароль от amoCRM и не изменяет данные карточки.

Хранение и прекращение работы

Результат отображается в интерфейсе текущей карточки. Виджет не создаёт отдельную базу данных и не хранит историю проверок на сервере. Чтобы прекратить работу, отключите приложение в amoMarket. Исходные данные продолжат храниться в amoCRM по правилам этой системы.

Сайт и обращения в поддержку

Этот справочный сайт размещён на GitHub Pages. Хостинг обрабатывает технические данные веб-запросов в соответствии с политикой GitHub. На сайте нет форм сбора контактов, собственной аналитики и рекламных скриптов.

Если вы отправляете обращение на support@tehprof.kz, в поддержку поступают адрес отправителя и содержание письма. Передавайте только сведения, необходимые для разбора проблемы. Не присылайте пароль, cookies, токены доступа или неотредактированные клиентские базы. Для примера используйте вымышленные значения.

Вопросы

Вопросы о данных и обращения относительно отправленных вами материалов принимаются по адресу support@tehprof.kz. Существенные изменения поведения виджета сопровождаются обновлением этого документа и описания версии.
